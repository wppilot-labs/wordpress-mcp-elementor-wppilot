v1.0.0 - 2026/08/08
* Initial public release.
* MCP server for WordPress, built on the WordPress Abilities API and the official MCP Adapter.
* Two ways in: OAuth 2.1 with PKCE and dynamic client registration, or WordPress application passwords.
* Generated connection configuration for Claude Code, Claude Desktop, Codex, Cursor, VS Code, GitHub Copilot, Antigravity CLI, Antigravity IDE, Windsurf, Zed, Cline, Roo Code, Kilo Code, Amazon Q, and OpenCode.
* Overview screen showing which AI clients are connected, how they authenticated, and how much they call.
* Safety profiles — Production Safe, Read Only, and Developer Full Access — enforced across ability registration, MCP dispatch, and direct REST execution.
* Destructive and critical operations require explicit confirmation, and supported mutations are recorded in a bounded, redacted change ledger with verified rollback.
* Per-credential rate limiting on ability execution, with read-only abilities exempt.
* Typed content, media, users, settings, extensions, navigation, and diagnostics operations, so raw developer primitives are rarely needed.
* Skills, site instructions, and a sandbox for agent-authored PHP, isolated behind directory guards.
* Diagnostics screen that probes the connection the way a client does and names what to fix.
* MCP and WPPilot REST responses validate the request host and send no-store security headers.

Releases before 1.0.0 were internal and are not part of the public history.
