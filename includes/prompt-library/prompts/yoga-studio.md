# Still Point Yoga — boutique yoga studio landing page

Design and build a **complete, production-quality landing page** for "Still Point Yoga", a small neighbourhood yoga studio. **You own the design.** If web search is available, research 2–3 genuinely well-designed studio or wellness sites first and form a point of view; then decide the layout, composition, and section design yourself. Do not fall back to a generic centered-hero + three-identical-cards template — bring editorial composition, asymmetry, scale contrast, and rhythm. **Vary your hero composition to fit this brand specifically — no photo in the hero at all, no lotus or sunrise imagery anywhere, and no card grids; the page should feel like breathing room, with the schedule as the first concrete thing a visitor meets.** The sections below define **what the page must communicate, not how it must look.**

## Style guide (constraints, not layout)

**Palette — flat colors only, no gradients:**

| Role | Value |
|---|---|
| Surface, light | `#E4E8DF` (sage) |
| Surface, white panels | `#FFFFFF` |
| Surface, dark bands | `#1F3A2C` (moss) |
| Ink / headings | `#1F3A2C` |
| Accent — use sparingly: one link, the intro offer, the "today" column | `#C8613A` (terracotta) |
| Muted body text | `#5F6B60` |
| Hairlines / dividers | `#CFD6CB` |

**Typography:** Display = **Cormorant Garamond** (fallback: EB Garamond), light weight, set **lowercase** and very large — headlines should feel exhaled, not shouted. Body = **Karla**, 16–18px, line-height ~1.8. Schedule and prices in Karla with tabular figures.

**Feel:** quiet and spacious — more margin than content; thin hairlines; no shadows; no icons in the hero. Photography appears only in the teachers section and one full-width band, graded soft and neutral.

**Motion:** almost none — a single slow fade on the hero headline; nothing else moves. Use only what the chosen builder provides natively; **no custom JavaScript and no hand-rolled motion CSS.**

## Design signature (make this page distinct — adapt as you see fit)
These are compositional cues, not layout mechanics. Use them to give this studio its own look rather than a generic template:
- **Hero:** type only, on sage: a lowercase headline set across the full width at the largest size the builder allows, a short right-aligned paragraph beneath it, and one terracotta text link ("see this week's classes") — no buttons, no image.
- **Schedule:** a true weekly grid, Mon–Sun as columns and time slots as rows, with today's column tinted; this is the page's centrepiece and should be larger than any other section.
- **Classes:** four tall, narrow columns separated by hairlines, each with a thin top rule, the class name in Cormorant, and three lines of Karla — no cards.
- **Shape language:** square corners; hairlines over boxes; a single moss band for the intro offer; terracotta only where a person is meant to act.

## Sections — what each must communicate (design them your way)

1. **Hero** — a calm, confident opener: the studio name small, one lowercase headline, one supporting sentence, one text link to the schedule.
2. **Intro offer** — the new-student offer below, set on the moss band as one clear sentence with a single action.
3. **Classes** — all four class types below, what each is for, and who it suits.
4. **Weekly schedule** — the full timetable below as a grid; every slot names the class, teacher, and duration.
5. **Teachers** — three teachers with a photo each, one line on training, one line on how they teach.
6. **Pricing** — drop-in, 10-class pack, and unlimited monthly, plus the intro offer restated; state what is included and that packs never expire.
7. **Reviews** — three distinct, believable student quotes with first names; write them yourself.
8. **Your first visit** — what to bring, arrival time, mats, and a working sign-up form (name, email, phone, experience level, preferred class time) built with the builder's native form element. If the builder has no form element, use a clearly labelled call/email call-to-action instead of omitting this.
9. **Visit** — address, phone, email, hours the desk is staffed, and a map if the builder supports one.
10. **Footer** — brand + tagline, quick links, contact, copyright.
